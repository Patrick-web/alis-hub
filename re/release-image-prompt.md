# Release Image Prompt — Raycast Style

Based on the Raycast release note art style, use this as the base prompt for every release image. Replace `[VERSION]`, `[FEATURE TITLE]`, and `[3D OBJECT DESCRIPTION]` per release.

---

## Base Prompt

A sleek, minimalist, dark-mode product announcement image in the Raycast release notes aesthetic. Split-panel composition on a matte black (#000000) background with very subtle dark blurred gradients adding depth.

**Left side — Typography:**
Version tag "[VERSION]" in small subtle grey text inside a light-grey-outlined rounded capsule. Below it, the feature title "[FEATURE TITLE]" in large, bold, clean white sans-serif (SF Pro or Inter style), left-aligned, two to three lines.

**Right side — 3D Visualization:**
[3D OBJECT DESCRIPTION]. High-quality abstract 3D render of translucent glass-like or frosted acrylic objects with smooth velvety matte finish, polished refractions and specular highlights. Jewel-toned iridescent gradient colors (electric blue, magenta, emerald green, or golden yellow). Isometric or three-quarter perspective. Cinematic low-key lighting with a single strong key light, soft colored light leaks and ambiance glow against the dark background. Soft diffused reflections on the dark floor below the objects.

Minimalist typography, bold white text title, translucent glass 3D render, smooth polished finish, low-key cinematic lighting, soft colored ambiance light leaks. Raycast release notes aesthetic.
